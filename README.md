# CHZZK Vertical Layout

**치지직(CHZZK) 세로 레이아웃 및 채팅창 크기 조절 프로젝트**

치지직 라이브 방송을 세로형 모니터(피벗)에서 보다 자유롭게 시청하기 위한 사용자 정의 레이아웃 프로젝트입니다.

Stylus와 Tampermonkey를 사용하여 기존 웹사이트의 화면 배치를 변경하고, 사용자가 영상과 채팅창의 비율을 직접 조절할 수 있도록 구현했습니다.

## 1. 개발 배경

치지직에서는 브라우저 창의 너비에 따라 영상과 채팅창의 배치가 자동으로 변경됩니다.

세로형 모니터에서 영상과 채팅을 위아래로 배치하더라도, 브라우저 창을 일정 너비 이상으로 확장하면 다시 좌우 배치로 전환되는 불편함이 있었습니다.

이를 해결하기 위해 개발자 도구로 웹페이지의 HTML 구조와 CSS 선택자를 확인하고, 사용자 정의 CSS를 적용했습니다.

이후 채팅창 높이가 고정되어 있다는 한계를 발견하여 드래그 방식의 높이 조절 기능을 추가했습니다.

## 2. 주요 기능

- **세로 레이아웃 유지:** 넓은 화면 모드에서도 영상 위 / 채팅 아래 배치 유지
- **채팅창 높이 조절:** 영상과 채팅 사이의 드래그 핸들로 높이 변경
- **설정 저장:** 조절한 채팅창 높이를 localStorage에 저장하고 복원
- **기존 모드 유지:** 좁은 화면 모드에서는 기존 레이아웃 유지

## 3. 사용 기술

| 기술 | 용도 |
|---|---|
| HTML / Chrome DevTools | 웹페이지 구조 및 요소 분석 |
| CSS / Flexbox | 영상과 채팅창 레이아웃 변경 |
| CSS Variables | 채팅창 높이 동적 제어 |
| JavaScript | 드래그 조절 기능 구현 |
| localStorage | 채팅창 높이 설정 저장 |
| Stylus | 사용자 정의 CSS 적용 |
| Tampermonkey | 사용자 JavaScript 실행 |

## 4. 파일 구성

- **chzzk-layout.css** — 세로 레이아웃 및 채팅창 높이 설정
- **chzzk-chat-resizer.user.js** — 드래그 핸들, 높이 조절 및 설정 저장

## 5. 설치 방법

### Stylus

1. 브라우저에 Stylus 확장 프로그램을 설치합니다.
2. 새 스타일을 생성합니다.
3. `chzzk-layout.css`의 내용을 복사하여 붙여넣습니다.
4. URL 적용 조건을 `https://chzzk.naver.com/live/`로 설정하고 저장합니다.

### Tampermonkey

1. 브라우저에 Tampermonkey 확장 프로그램을 설치합니다.
2. 새 사용자 스크립트를 생성합니다.
3. `chzzk-chat-resizer.user.js`의 전체 코드를 붙여넣습니다.
4. 스크립트를 저장하고 활성화합니다.
5. 필요하다면 크롬 확장 프로그램 설정에서 사용자 스크립트 실행을 허용합니다.

## 6. 개발 및 개선 기록

### v1.0 — 세로 레이아웃 구현

**문제:** 브라우저 너비에 따라 세로 배치가 자동으로 해제됨.

**개선:** 넓은 화면 모드를 식별하는 CSS 선택자를 적용하여 영상과 채팅창을 세로로 배치.

### v1.1.0 — 채팅창 높이 조절 기능 추가

**문제:** 세로 레이아웃 구현 후에도 채팅창 높이가 고정되어 있음.

**개선:**
- CSS 고정 높이를 변수로 변경
- JavaScript 기반 드래그 핸들 추가
- 변경한 높이 저장 및 복원

**검증:** 정의한 주요 기능 요구사항 5개에 대한 수동 동작 확인 완료.

- Issue #1 — 채팅창 높이 조절 기능 개선
- Pull Request #2 — CSS 수정 및 JavaScript 추가 후 main 병합

### v1.1.1 — 드래그 핸들 표시 지연 개선

**문제:** 방송 페이지에서 넓은 화면 모드로 전환한 후 드래그 핸들이 약 0.5초 늦게 나타나는 현상 발생.

**원인 조사:** 기존 `setInterval(setup, 1200)`의 반복 검사 간격이 표시 지연에 영향을 미치는 것을 테스트로 확인.

**개선:**
- `setInterval` 기반의 주기적 검사를 `MutationObserver` 방식으로 변경
- 채팅창 내부에서만 발생한 DOM 변경은 불필요한 `setup()` 실행에서 제외
- `requestAnimationFrame()`을 이용해 연속적인 변경에 따른 중복 실행 감소
- 사용자 스크립트 버전 1.1.1로 변경

**검증:** 핸들 표시 속도, 드래그 조절, 높이 저장 및 복원, 화면 모드 전환, 방송 페이지 이동 등 주요 기능 테스트 완료.

- Issue #3 — 드래그 핸들 표시 지연 개선
- Pull Request #4 — MutationObserver 적용 후 main 병합

## 7. 호환성 및 향후 개선


### 호환성 관련 참고 사항

- 치지직 웹페이지 구조 변경 시 CSS 선택자 및 스크립트 수정이 필요할 수 있음

### 향후 개선 계획

**1. Stylus와 Tampermonkey 기능 통합**
- 현재 분리된 CSS와 JavaScript를 하나의 사용자 스크립트로 통합
- Tampermonkey만으로 레이아웃 변경과 채팅창 크기 조절 기능 실행
- 설치 및 관리 과정 간소화

**2. 독립적인 Chrome 확장 프로그램 개발 검토**
- Stylus와 Tampermonkey 없이 사용할 수 있는 확장 프로그램 제작
- CSS와 JavaScript를 하나의 확장 프로그램으로 구성
- 사용자 편의성 및 설정 관리 기능 개선
